# Перенос в Unity

## Канвасы
- Все панели — **World Space Canvas**, масштаб 0.001, дистанция до панели 1.8–2.2 м, высота центра на уровне глаз.
- Опорное разрешение: 1920×1080 на кадр. 1 px макета ≈ 1 пиксель канваса, `Canvas Scaler` → Dynamic Pixels Per Unit = 2.
- Боковые панели (профиль, настройки) наклонены к игроку на 18° по Y. Центральная — прямо.
- HUD (таймер, баллы, подсказка направления) — Canvas, привязанный к камере с лёгким отставанием (lazy follow), дистанция 1.2 м.
- Газоанализатор — на левом запястье (child контроллера), поворот к взгляду.

## Ввод
- Луч: `XR Ray Interactor` + `XR UI Input Module`. Цвет луча `--ray`, курсор — реткл 34 px.
- Выбор — триггер, телепорт/ходьба — стик. Минимальная цель для луча — 84 px (`--btn-h`).

## Токены → Unity
Создайте `ScriptableObject UiTheme` с полями по `design/tokens.css`:
blue `#02213F`, ink `#0F2233`, mute `#5B6E7C`, heat `#F26B1D`, ray `#1F8FE0`, ok `#1F9D55`, warn `#E5A500`, bad `#D92D20`.
Радиусы: панель 28, карточка 22, кнопка 44 (Sprite 9-slice).
Размеры шрифта: заголовок 76, H2 40, текст 28, мелкий 23 — не меньше 23 в шлеме.
Шрифт: заменить на Roboto Condensed (заголовки) и Fira Sans (текст), оба с кириллицей; для TMP сделать Font Asset с набором Cyrillic.

## Компоненты (префабы)
Panel, ButtonPrimary (heat), ButtonSecondary (ghost), ButtonDanger, Chip, ModuleCard (+selected), ProgressBar, ChecklistItem, InteractionHint (над объектом), GasMeter, AlarmBanner, ResultRow.

## Логотип
`assets/logo/nlmk.svg` → импортировать как Sprite (Vector Graphics) и поставить в шапку лобби, модуля и итогов.

## Стекло (глассморфизм)
- Панель = Image со спрайтом 9-slice (радиус 36) + материал размытия фона. Для Built-in/URP: Render Texture с блюром камеры
  (Kawase/Dual blur, 2 прохода) под панелью; в Quest лучше 1/4 разрешения. Дешёвый fallback — полупрозрачный синий `rgba(14,46,96,.34)`.
- Кромка: отдельный спрайт-обводка 1.6 px с градиентом от белого (верх-лево) к прозрачному — это даёт эффект стекла.
- Фон за панелями слегка размыт (depth of field), чтобы стекло читалось и текст не терялся.
- Логотип: нужна белая версия `assets/logo/nlmk.svg`.
